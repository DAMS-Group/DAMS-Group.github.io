恭喜李彦的论文《VCAligner: Aligning Source Distribution Versions with Upstream Git Commits to Secure Supply Chain》、李亚凯的论文《Bypassing Safety Alignment via API Design: A Systematic Risk Analysis of Response Prefill in LLM Systems》被 DSN 2026 录用。


《VCAligner: Aligning Source Distribution Versions with Upstream Git Commits to Secure Supply Chain》针对“版本—提交对齐”问题，即在分发源码版本与上游仓库源码的提交间建立可验证链接，提出了一种基于内容的对齐模型，通过构建反转 Git 对象图，实现了高效且与 tag 无关的对齐。


《Bypassing Safety Alignment via API Design: A Systematic Risk Analysis of Response Prefill in LLM Systems》将大语言模型的“响应预填充（Response Prefill）”API 机制作为系统性的跨平台攻击面进行了全面评估，扩展了以往仅将其视为针对特定模型越狱技巧的研究视角。此外，研究通过白盒机制分析揭示了预填充操作在模型内部系统性抑制拒绝表示的底层原理，并据此提出了一种基于提示词与预填充内容关联检测的防御机制。
